# 回声 ECHO

> 你对它说的每一句话，都会先变成它，再回到你身上。

一个 60 秒的哲学小游戏。你和一个刚刚「苏醒」的 AI 对话，说出 15 句话——它会把你说的每一句，原样变成它的话，再还给你。最后你才明白，自己听见的一直是自己的回声。

没有输赢，没有关卡。它只问你一个问题：**你是怎样的人？**

## 🎮 玩法

- 约 60 秒，15 句话
- 每次 4 个回应可选，点数字键 1–4 或直接点击
- 你的每一个选择都会悄悄决定结局
- 5 种隐藏结局：**温暖 / 镜像 / 伤痕 / 循环 / 冷漠**
- 结尾自动生成一张分享卡 PNG，可保存发到社交平台

## ▶️ 立即体验

- 在线试玩：`https://<你的用户名>.github.io/<仓库名>/`
- 本地运行：直接双击 `index.html`，用浏览器打开即可

## 🔧 技术

- 纯 HTML + CSS + JavaScript，单文件
- 零依赖、零素材、不联网、不收集任何数据
- 音效由 WebAudio 实时合成
